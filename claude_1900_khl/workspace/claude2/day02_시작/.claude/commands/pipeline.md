작업내용: $ARGUMENTS

다음 작업을 아래 서브에이전트들에게 **반드시 이 순서대로** 위임해서 작업을 처리하세요. 각 단계가 끝나면 그 결과(요약)을 다음 서브에이전트에게 컨텍스트로 전달하세요. 중간 단계를 건너뛰거나 순서를 바꾸지 마세요.

1. **@test_analysis_agent** 서브에이전트: 요구사항과 관련된 코드/자료를 받아서 **작업내용** 처리한다. 
2. **@test_db_agent** 서브에이전트: 1번 결과를 바탕으로 사용자의 요구사항에 맞는 스키마를 설계하고, 규칙에 맞게 컬럼명, 테이블명, 타입 설계한다.
3. **@test_back_agent** 서브에이전트: 2번 결과를 바탕으로 설계된 스키마에 데이터를 CRUD할 수 있는 백엔드 로직을 구현
4. **@test_front_agent** 서브에이전트: 3번 결과를 바탕으로 설계된 백엔드 로직의 엔드포인트로 데이터를 요청하고 응답을 받을 수 있게 설계하고, 요구사항에 맞는 화면을 구현

모든 단계가 끝나면 전체 과정을 한 번에 요약해서 사용자에게 보고하세요.
